🔄 Update Notification System

This system automatically detects when new versions are deployed to GitHub Pages and notifies users with an elegant update prompt.

🚀 How it works:

  • Automatic Detection: Checks for updates every 30 seconds by comparing version.json
  • Smart Caching: Only updates when build number or version changes
  • User-Friendly: Shows a beautiful notification with update options
  • Force Refresh: Clears cache and fetches latest assets when user clicks update

  4. Cache Strategy: Force refresh cache with cache-busting for new updates

🔧 To deploy updates:

1. Update version.json with new version/build number
2. Deploy to GitHub Pages
3. Users will automatically see update notification
4. When they click "Update Now", latest assets are fetched
